Equivalence of N-CLL with CLL in Linear Logic
=============================================

In this project I proved the equivalence of The Natural Deduction system (N-CLL) with the Sequent Calculus system (CLL) in Linear Logic. The main source for this project was *Lectures on Linear Logic* by A. S. Troelstra. Both of the systems were used according to Troelstra's notation and the definition for the main theorem and also interpretations were copied directly from the text of this source. I got the main idea on how to prove the theorem from the brief notes after the statement of the theorem and was able to formalize a complete proof by stating 4 additional lemmas, proving them, strengthening the statement of the theorem on both sides and using induction on the depth of the proof tree.
